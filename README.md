# React Task 1

This project is a simple React application created using Vite. It includes basic setup and configuration for a React project with Tailwind CSS for styling.

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:

git clone https://github.com/your-username/react-task-1.git
cd react-task-1

2. Install dependencies:

npm install
# or
yarn install

### Running the Project

To start the development server, run:

npm run dev
# or
yarn dev

This will start the Vite development server and open the application in your default browser.

### Building the Project

To build the project for production, run:

npm run build
# or
yarn build

The built files will be output to the `dist` directory.


## Project Configuration

### Vite Configuration

The Vite configuration is located in `vite.config.js`. It includes the React plugin for Vite.

### Tailwind CSS Configuration

The Tailwind CSS configuration is located in `tailwind.config.js`. It specifies the content paths and theme extensions.

### PostCSS Configuration

The PostCSS configuration is located in `postcss.config.js`. It includes Tailwind CSS and Autoprefixer plugins.

### ESLint Configuration

The ESLint configuration is located in `eslint.config.js`. It includes recommended rules for JavaScript and React.

## Components

### App Component

The main application component is located in `src/components/App.jsx`. It renders the `Home` component.

### Home Component

The home page component is located in `src/pages/Home.jsx`. It renders the `Card` component.

### Card Component

The card component is located in Card.jsx. It displays a simple card with some text.

## Styling

The project uses Tailwind CSS for styling. The main stylesheet is located in `src/index.css`.
